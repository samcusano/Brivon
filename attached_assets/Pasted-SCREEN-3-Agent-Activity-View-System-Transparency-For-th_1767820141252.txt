Key Design Decisions:

Progress bars: Visual indication of how far through a task
Hierarchical task breakdown: What the agent is doing → What it's found → Recent actions
Awaiting input is prominent: Users know when they're blocking agents
Recent completions: Awareness of what just finished (builds trust over time)
Agent naming convention: Type-ID (e.g., VendorRiskMonitor-07) makes it traceable in audit logs
