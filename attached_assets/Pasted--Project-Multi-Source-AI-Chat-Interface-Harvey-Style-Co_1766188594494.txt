# Project: Multi-Source AI Chat Interface (Harvey Style)

## Context
Build a desktop-first AI chat interface that handles bulk document analysis with transparent multi-source data integration. Users can extract hundreds of questions from documents and get responses that cite from multiple evolving data sources.

## Design System Reference:

### Visual Language
- **Color Palette**:
Base / Background: Soft beige (#F5EFE6)
Primary Accent: Warm caramel (#D8BFA4)
Secondary Accent: Muted terracotta (#C29984)
Text / Contrast: #31263B
Highlight / Interactive: Soft (#31263b17)
- Accents: Deep black for CTAs, subtle borders (#E5E5E5)
- Trust indicators: Soft green for verified sources
- **Typography**:
- Sans-serif, likely Cinetype or similar
- Hierarchy: 24px headlines, 16px body, 14px metadata
- Generous line-height (1.6+)
- **Spacing**:
- Card padding: 24px
- Component gaps: 16-24px
- Section margins: 48px+
- **Components Style**:
- Rounded corners: 8-12px on cards
- Subtle shadows: 0 1px 3px rgba(0,0,0,0.06)
- Hover states: slight scale (1.01) + shadow increase
- Icons: 20px, stroke-based, neutral gray

### 3. Response Display with Multi-Source Citations
Chat message bubbles that include:
- **Message Content**: Standard markdown support
- **Inline Citations**:
- Small superscript numbers [1] [2] [3]
- Color-coded by source type:
- Pastel blue: documents (#337ab7)
- Pastel purple: MCPs
- Pastel green: web (#8dc572)
- Pastel orange: memory (#f0ad4e)
- **Source Footer** (expandable):
- "Sources used:  Q3-Report.pdf |  Salesforce API |  competitor-analysis.com"
- Click to expand full citation details with excerpts
- **Confidence Indicator**:
- Subtle bar or badge: "High confidence" (green) / "Mixed sources" (amber) / "Limited data" (gray)

### 4. Bulk Question Extraction Flow
After document upload, show modal/panel:
- **Header**: "Found 247 questions in your document"
- **Preview List**:
- First 5 questions visible
- Checkbox selection (select all/none)
- Category tags auto-detected (Financial, Legal, Technical, etc.)
- **Actions**:
- "Answer all questions" (primary CTA)
- "Select specific questions" (opens full list with search/filter)
- "Configure sources for batch" (links to source panel)
- **Progress Tracking**:
- Once started: persistent bottom bar
- "Answering question 45 of 247... | Pause | Stop"
- Estimated time remaining

### 5. Question Queue Manager
Dedicated view accessible from sidebar:
- **Tabs**: All (247) | Answered (45) | Pending (202) | Failed (0)
- **List View**:
- Question text (truncated)
- Status badge (✓ Answered, ⏳ In progress, ⏸ Paused)
- Source icons used for answer
- Click to view full answer
- **Batch Actions**:
- Re-run with different sources
- Export all answers (CSV, JSON, PDF)
- Delete/archive questions

## Technical Stack
- **Framework**: React 18+ with TypeScript
- **Styling**: ShadCN CSS
- **State Management**: Zustand or React Context for source configuration
- **Components**:
- Radix Icons for icons
- Framer Motion for micro-interactions
- React Dropzone for file uploads
- **Mock Data**:
- Sample documents, questions, and responses
- Simulated MCP connections (Salesforce, Google Drive, Slack)

## Key Interactions to Implement

1. **Drag-and-drop file upload** with visual feedback
2. **Source toggle animation** (slide in/out, fade)
3. **Citation hover popover** showing excerpt preview
4. **Bulk question extraction** with smooth modal transitions
5. **Real-time progress bar** for batch processing
6. **Source panel collapse/expand** with smooth width transition

## Mental Model Goals
User should feel:
- **In control**: Clear what AI can access, easy to change
- **Informed**: Always know where answers come from
- **Efficient**: Handle hundreds of queries without overwhelm
- **Confident**: Trust built through transparency, not buried in fine print

## Success Criteria
- [ ] Interface feels calm and confident (not feature-overload)
- [ ] Source configuration is always visible but not intrusive
- [ ] Citations are informative but don't break reading flow
- [ ] Bulk operations feel manageable, not chaotic
- [ ] Could realistically scale to 1000+ questions
- [ ] Built in 2-4 hours (prioritize core interactions over polish)

## Deliver
Single-page React app that demonstrates:
1. Uploading document → extracting questions
2. Configuring which sources AI can use
3. Viewing responses with multi-source citations
4. Managing bulk question queue

Focus on interaction patterns and system thinking over pixel perfection. Make it feel professional, trustworthy, slightly warm.
